# objectarx_sdks

# 📦 Legacy ObjectARX SDK Archive (2000–2012)

This repository is a curated archive of historical **ObjectARX SDKs** from the years **2000 to 2012**, preserved for learning, reference, and compatibility purposes. These SDKs have played a foundational role in the evolution of AutoCAD customization and continue to serve developers working on older versions of AutoCAD or maintaining legacy systems.

> 🔎 This is a community-driven initiative to **make hard-to-find SDK versions more accessible**, especially for those working with historic enterprise codebases.

---

## 🧰 What's Included

- Official ObjectARX SDKs from **AutoCAD 2000** through **AutoCAD 2012**
- Companion samples, documentation, and utilities from those SDKs
- Optional fixes or patches when available
- Structured folder layout by AutoCAD version

---

## 📚 Why This Matters

While Autodesk offers current SDKs via their [Autodesk Developer Portal](https://aps.autodesk.com/), older versions are increasingly difficult to find but still essential for:

- **Maintaining legacy AutoCAD plug-ins**
- **Reverse engineering old workflows**
- **Academic and historical research**
- **Transitioning to modern APIs like .NET or APS (formerly Forge)**
